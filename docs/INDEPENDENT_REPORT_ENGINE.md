# 独立报告引擎与生产接入

本引擎复用现有 `report_service`，完全不调用 Violoop、Agenda、桌面设备或用户绝对路径。生产研究只使用 live provider；合成内容仅用于隔离测试，不能写入网站或知识库。

## 保留的业务合同

1. 经济、人口、交通土地园区、生活配套、产业方向、区域竞争、政策七类基础调研。
2. 产业链全景及本地已具备、缺失、薄弱环节。
3. 根据产业方向与缺口开展三个方向的企业调研：每方向至少25个候选，standard至少15个最终企业、deep至少25个最终企业。模式随任务定义持久保存，重试不能改变；深度模式分五批、每批5家检索和核验，避免扩大单次研究调用。落地状态、扩产来源、发布日期和不确定性显式保存。未知事实不能写成确定结论。
4. 经济、政策及高星企业信号的独立交叉核验；匹配分数由 Python 按既有权重计算，风险反向计分。
5. 行动计划、领导摘要、精简报告。共16份 Markdown，standard有77个、deep有83个持久研究子步骤，再独立构建交付包。
6. 完整与精简 Word 保持仿宋、公文字号、1.5倍行距、页边距及既有章节顺序；19个载荷的清单保存大小与 SHA256。
7. RAG主题仍为主导产业与产业链、园区与承载条件、链主与存量企业、政策规划。每主题最多60条；总数不足40不发布。精简正文写入 REPORTSTATE。

出处：`HUIXIAOZHAO_REPORT_SKILL.md`、`full_contract.py`、`word_export.py`。行数、来源数量和模型交叉核验属于门禁，不能当作事实正确的证明。公开知识库仅能接受真实完整报告。

## 运行和恢复

`server.py` 启动一个受监督的 `python -m report_service.hosted` 子进程，无需新增云服务。多个副本共享已有 PostgreSQL，由事务锁和有期限的租约控制唯一有效认领。研究调用在可终止子进程内，单次有硬截止；失效 worker 无权写检查点或完成。

独立镜像 `Dockerfile.full-report` 也使用 hosted 入口，默认等待真实研究配置；不启动合成报告 worker。本次不会创建或部署额外收费服务。

研究结果、尝试、失败事件、进展时间、下一次退避时间和最终文件全部持久存数据库。云端临时盘只用于构建文件；数据库存齐并校验载荷后才可以确认完成。重启后从已提交的子步骤继续；下载不依赖旧临时目录。外部调用不保证恰好一次，已经提交的检查点不会因为交付失败重做。

网络中断不能继续获取外部资料，但任务不会被假标为成功或丢弃；连接恢复后从检查点接续。暂时性错误持续退避，无总次数/累计时间放弃策略。失效认证与配置错误明确失败并保留成果，需要修复后运维恢复。

运维配置只读检查：`python -m report_service.hosted --check`（不连数据库、不检索、不调用模型，仅输出缺少的配置名）。修复配置后可用 `python -m report_service.hosted --resume-request rr申请ID` 恢复该申请；保留所有已完成检查点。取消或完成的报告不能通过该命令复活。

取消/重置在下一次租约检查终止本地研究子进程；远端已接受的请求可能仍计费。取消不删除已保存研究成果，也不会发布取消后的报告。

## 网站兼容

沿用 REPORT_REQUESTS、现有申请/取消/下载接口以及“推送到RAG”按钮。内部适配器使用固定网站队列隔离标识，不向前端引入服务凭据，不增加公开生成API。它不是新的用户身份系统；既有网站鉴权问题不由本改动解决。

新引擎的进度、城市及文件由服务器管理，旧消费者和旧浏览器快照不能通过 `/api/sync` 改写。旧脚本读取 `/api/sync` 时只看到历史已认领或已完成的旧报告记录；新报告以及有效但尚未认领的历史 pending 申请均隐藏。网站通过 `X-HXZ-Report-Client: website` 选择完整视图，已打开页面的同源浏览器 Fetch Metadata 也兼容。此标识只选择视图，不是服务凭据或认证授权。

队列读取始终使用 `Cache-Control: no-store` 和涵盖视图选择头的 `Vary`，防止两类客户端共享错误的缓存视图。浏览器元数据字段与缓存变化依据 [W3C Fetch Metadata 规范](https://w3c.github.io/webappsec-fetch-metadata/)。

客户端经 `/api/sync` 将新引擎或有效未认领的历史 pending 任务认领为 running，或写入新的 claimTs，会收到 HTTP 409 与 `rejected=server-owned-report`，整次写入回滚。选择完整视图也不会获得认领权限。服务器内部 worker 直接使用数据库事务和租约，不经过客户端认领接口。因此，旧轮询保持开启也无法从旧视图发现新报告并继续派发。用户取消、旧浏览器快照合并、旧请求处理以及原报告下载合同保留。

既有完成报告保持原字节；原 running 报告不被自动重建、导入或伪装完成。RAG发布在单次事务中完成项目、城市基础包指针、正文和回执写入，重复请求不重复发布，不新建账号或密码。

报告完成与知识库发布分开重试；某报告交付异常不会阻止其他报告研究。REPORTSTATE的 score 来自核验一致项比例，既不是任意固定百分比，也不是事实可信度认证。

## 生产配置与切换

网站默认使用独立引擎：申请所有权、旧队列视图隔离、认领拒绝、云端发布不受启用开关控制。真实付费研究仍须明确配置 `HXZ_ENABLE_LIVE=1`；缺失配置只等待，不回退 Violoop/Agenda。`HXZ_REPORT_ENGINE` 可省略；历史配置为 `standalone` 仍兼容，其他值会显示配置缺项并暂停执行，不改变独立所有权。Supervisor 默认启动，配置未就绪时不启动研究子进程。

现有 DATABASE_URL 复用。已有 DEEPSEEK_API_KEY 在内存中适配为模型配置，不复制、输出或创建凭据。也支持显式 HXZ_MODEL_URL/HXZ_MODEL_KEY/HXZ_MODEL_NAME。

真实检索需要 `HXZ_SEARCH_KEY` 和所选 Brave/Exa 配置；已有 EXA_API_KEY 可在内存中适配。必须是可用的独立检索连接，不能仅依靠模型记忆或从桌面凭据库搬运密钥。检索结果保存发布日期及实际检索时间。

启用前验证服务端的队列视图隔离与 HTTP 409 认领拒绝，并用隔离真实城市报告验证来源、企业真实性、时效、Word可读性和发布。独立服务无需关闭 Violoop 才能运行；历史旧 running/done 任务不自动迁移；有效未认领的 pending 申请由独立 worker 接管。历史已完成 Word 下载保持原字节；尚未发布且没有独立研究包的旧报告推送返回 409，提示重新生成，不再留下等待桌面 Agent 的发布请求。已发布旧报告的重复推送仍返回原回执。应用无法限制其他产品在自己的环境中任意使用其第三方 API。

2026-10-04 已只读确认当前生产配置了 DATABASE_URL、DEEPSEEK_API_KEY、HXZ_SEARCH_PROVIDER、HXZ_SEARCH_KEY，未读取或导出凭据。检索鉴权和真实生成尚未验收，真实调用仍由显式 live 配置控制。一次具体生产部署、启用和隔离真实报告验收仍需通过部署工具审批。

`/health` 的 `report_engine` 字段仅返回配置缺项名称、独立 supervisor 与 worker 进程状态；不返回检索密钥、数据库地址或凭据。`scope=process_and_configuration_only` 明确表示它不能证明检索鉴权或研究结果通过验收。运维核验时只读取该字段，旧健康响应中的其他字段不作为报告验收证据。

## 验收证据

隔离测试分别验证：队列提交与重试、取消和旧状态写入保护、半包/合成发布拒绝、发布失败与幂等恢复、单个交付失败不阻止其他任务；PostgreSQL CI验证20并发认领、租约失效和重启接续、取消吊销、临时盘丢失后的19载荷下载及篡改拒绝。

真实 HTTP 回归额外验证旧脚本看不到新任务、认领返回409且不写入、网站可查看并取消、旧请求仍可认领以及原下载字节不变；数据库事务回归验证冲突回滚，缺失事务保护时不能降级为无锁写入。

这些故障测试证明流程和数据保护，不能替代真实来源验收。真实生成、可用检索连接及服务端隔离验证仍是正式启用的必需条件。

## 2026-10-08 默认独立路由修复

- 新申请提交即标记 full-v1；有效未认领的历史 pending 在 worker 摄取前也受到读取隔离和认领保护，避免旧快照抢先认领。旧 running/done 不重跑、不伪装完成。
- 关闭执行或缺少配置不会让申请回到旧队列。健康只报告配置与进程，管理端显示“报告服务未就绪，申请已保存”；配置/认证故障保留成果并提示管理员修复。
- Word 完成与知识库发布分开展示，只有 pushed 回执才显示独立报告材料已入库。
- 网页推送统一使用事务适配器；无数据库的本地回归使用带文件锁的原子写入，云端研究仍要求 PostgreSQL。
- worker 重试日志只含 ingest/mirror/worker 阶段、异常类型与受限 SQLSTATE，不输出异常正文、SQL 或凭据。
- readiness 在本地检查 HTTPS endpoint 和搜索 provider 的合法性，不访问网络；配置合法不等于上游鉴权或事实质量通过。

本次代码修改不自动取消历史运行申请，不调用真实模型，不启动新的真实城市报告。默认独立路由的生产部署与真实报告验收仍须分别确认。
