## Changes

- Reject invalid sync JSON and non-object state without persistence.
- Abort sync persistence after failed storage reads or merge exceptions.
- Report failed database persistence for knowledge uploads.
- Wait for server acknowledgement before showing demand submission success; retry without duplicate demand creation.
- Fail the JavaScript build gate when required pages/scripts are absent.
- Add 12 Python and 10 Node regression tests to CI.
