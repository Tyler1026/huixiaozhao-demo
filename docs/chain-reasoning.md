# 产业链节点研判

事实评价与补链优先级分开保存。`chain-assessment-v1` 保留原文事实判断；`chain-judgment-v2` 给出经过第二次模型调用复核的前提、推论、行动建议和限制。复核检验论证一致性，不代表完成线下事实认证。

- 绿色：原文支持本地已有相关基础。
- 黄色：政策培育方向、与本地相关的行业挑战，或经过企业身份与产品资料绑定的业务布局线索；业务布局不代表本地产能。
- 红色：明确本地约束、供需不匹配、与本地实际基础关联的具体依赖风险，或政策明确点名的补链瓶颈。后两项须显示为分析推论，不能改写成实测本地缺口。
- 灰色：当前材料不能形成有效节点论证；无检索结果不等于产业缺失。

生成时先检索并构图，再为最多六个跨环节节点补充公开资料。仅原文支持、对象一致、地区与时间范围一致的论证才接受；模型失败或复核不通过时保留已有研判。

## 公开原文库

`data/public-research/*.json` 只存实际取得的公开原文和来源元信息，不存节点评分、颜色或预设结论。`backend/public_research.py` 检查 URL、全文哈希、原文引用与稳定 ID。企业官网须由已验证的官方披露中“公司网址”字段提供域名证明。所有入库材料保留原始归档时间、PDF 摘录范围，界面标明归档命中，不冒充本次联网抓取。

全国比例不能用作区级比例，注册地址不能当作生产地点，父类短板不能分摊给所有子类，测试服务瓶颈不能归给产品本体。公开原文库仍须持续维护来源时期与后续变化；归档匹配不等于内容时效已经复核。
