# 产业链实际薄弱程度评价

`chain-assessment-v1` 继续保存原文事实；`chain-judgment-v3` 保存逐环节实际评价。政策规划只作中性背景，不参与判色。旧版政策优先级不再作为新评价失败时的回退结果。

- 绿色（已有支撑）：对应具体环节已有在用、交付、运行或生产证据。
- 黄色（存在短板）：有实际活动，但有明确供应、依赖、验证或交付阶段的约束。
- 红色（明显薄弱）：原文与比较基准支持严重瓶颈、关键输入受制或商业交付成熟度低。
- 灰色（尚不能评价）：缺少必要事实或复核未通过，不等于产业缺失。

每项显示比较基准、原文前提、相反证据、范围和待补材料。分别标识本地实际条件、关联企业业务和行业共性约束；企业的外地制造/交付不视为本地产能。整链仅展示分布，不平均成总分。注册、政策、展会、意向订单和未来目标不能冒充生产、交付和实测。

生成时进行实时公开检索，并针对最多30个节点分组补查，受总检索时间预算约束。服务器先绑定原文句、对象、数值与地区并形成可选事实编号；模型按8个节点一组选择事实进行比较，再由独立模型调用复核。模型未形成有效结论时，只有已有实际运行/交付原文的节点可提出“已有支撑”基线，仍须通过相同独立复核。调用失败或论证不成立的环节保留灰色，不机械补足三种颜色。模型复核验证论证一致性，不代表线下审计。

## 公开原文库

`data/public-research/*.json` 只保存实际取得的原文与来源元信息，不保存节点评分、颜色或预设结论。`backend/public_research.py` 校验URL、全文哈希、原文引用与稳定ID。企业官网须由已验证的官方披露中的公司网址字段提供域名证明。保留归档时间与PDF摘录范围，并区分归档命中与本次实时联网抓取。

全国比例不能替代区级比例；外地供应商可作为替代或对标证据，不能充作本地产能。父类约束不能直接分摊给所有子类，试验服务瓶颈不能归给产品本体。归档可追溯不代表资料最新，必须保留来源日期并核对后续进展。
